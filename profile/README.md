# MemoryZ

대학생을 위한 암기·복습 학습 앱을 만듭니다.

- **블라인더** — 그림과 표의 이름표를 가리고 떠올리며 외워요
- **줄줄** — 긴 글·코드·수식을 단계별로 가리며 익혀요
- **간격 반복(FSRS)** — 잊을 때쯤 다시 복습하도록 일정을 잡아 줘요

의약·보건·생명, 공학·정보 분야 학습자를 먼저 생각하며 만들고 있습니다. 지금은 개발 중이며, 소식은 이곳에서 알려 드릴게요.
